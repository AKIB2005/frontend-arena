# Grantly pitch

## 30-second pitch

Grantly helps students stop guessing which scholarships are worth their time. Build a lightweight profile, see a transparent match score with met, missing, and unknown criteria, then save the best opportunities into a deadline-aware tracker.

## 90-second demo script

1. Start on Home and move the live hero income slider; the real ranked shortlist changes.
2. Choose **Try demo profile** to jump into ranked Discover results.
3. Open a scholarship detail page and show the eligibility breakdown plus Coach notes.
4. Save the scholarship and show the confirmation stamp.
5. Open **My tracker**, move the scholarship through the stages, and show the document checklist and calendar export.
6. Return to Dashboard to show funding, pipeline, and next deadlines.

## Likely judge questions

- **Why a match score?** It prioritizes opportunities while keeping every contributing criterion visible.
- **How are unknown values handled?** Unspecified profile values are skipped rather than treated as failures; the UI labels them as not checked.
- **How is accessibility handled?** Native controls, visible focus, keyboard paths, semantic labels, reduced-motion support, and contrast-tested tokens.
- **How does motion respect reduced motion?** The system hook and media query remove movement-heavy effects while preserving state changes.
- **What would you build next?** Connect verified scholarship sources and add server-backed reminders without changing the transparent scoring contract.
